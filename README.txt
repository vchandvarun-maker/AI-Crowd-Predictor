BusPulse Working Prototype

1. Extract this ZIP file.
2. Open index.html in Microsoft Edge or Google Chrome.
3. Try bus numbers: UP21 AB 1234, UP21 CD 5678, UP16 XY 9012.
4. Use Try Demo QR to test the QR flow.

Note: This is a hackathon demo with simulated bus data. It is not connected to live GPS or real transport systems.
